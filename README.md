# 劳动仲裁助手（H5 测试版）

劳动者用大白话描述遭遇，系统追问事实、对照法条列出可主张的请求、测算金额、出可行性报告、整理证据目录、生成仲裁申请书。首批支持违法解除（2N）、拖欠工资、未签书面劳动合同二倍工资；覆盖中国大陆所有城市。

在线测试版：https://claude.ai/artifact/JrxuKu61QJL81aLoFQqM44

## 三明治架构（产品原则）

两头靠 AI 吞吐非标信息，中间靠纯代码锁死确定性。

**流水线**：用户乱序截图/口述 → 模型提取成结构化参数 → 用户确认/微调参数 → 纯代码引擎算出精确金额并生成文书 → 交付给用户。

**大模型永远不能直接输出最终赔偿数字给用户。**

| 环节 | 谁来做 | 代码位置 |
| --- | --- | --- |
| 口语意图归纳、追问 | 模型（不可用时退回关键词） | `web/app.js` 的 `extract`；追问顺序由 `engine/facts.js` 决定 |
| 证据照片识别（劳动合同、身份证、营业执照、解除通知、工资条、社保） | 模型只抄照片上的字段，写入规则由代码定 | `engine/docs.js` |
| 工资条平均月工资 | 模型只抄每月应发/实发，平均数由代码算 | `engine/docs.js` 的 `averageGross` |
| 补正对话（报告后想到啥说啥：质证、细节、手上的证据） | 模型抽事实和提到的证据，代码合并、重算并列出变化 | `web/app.js` 的 `supplement` |
| 合并案件记录 | 纯代码：对话、补正、材料识别、证据、请求汇成一份，去掉金额和待确认参数 | `engine/flow.js` 的 `buildRecord` |
| 事实与理由、证据目录「证明内容」 | 模型根据合并记录总结，不给金额；输出经代码校验（不许有金额、不许有记录之外的日期），不合格退回代码模板 | `web/app.js` 的 `draftReasons`、`organizeEvidence`，`engine/flow.js` 的 `checkReasons` |
| 金额：工作年限折算、社平 3 倍封顶、12 年上限、最低工资兜底、二倍工资 11 个月上限与时效、欠薪 | 纯代码 | `engine/engine.js` |
| 补偿类型判定：2N / N / N+代通知金 / 0 | 纯代码 | `engine/engine.js` 的 `severance` |
| 流程状态机：哪一步能进、卡在哪 | 纯代码 | `engine/flow.js` 的 `gates` |
| 参数确认：模型读出的计算参数先标「待确认」，用户确认前不出金额 | 纯代码 | `engine/flow.js` 的 `unconfirmed`，`web/app.js` 的 `st.pending` |
| 申请书：法定必填项校验、仲裁请求句式（金额只从计算引擎来） | 纯代码 | `engine/flow.js` 的 `requiredMissing`、`requestLines` |
| 申请书格式、份数 | 地区参数 | `rules/regions.js` 的 `application_format` |

**信息链**：所有页面读写同一份案件数据（`st.facts`、`st.app` 当事人、`st.evidence`），每个字段在 `st.sources` 里记来源，页面上显示「来自身份证照片」「来自你在对话里说的」。写入口统一走 `engine/docs.js` 的 `apply`：
- 来源优先级：用户确认或手改 > 身份证、营业执照 > 其他材料 > 对话 > 推断。不影响结论的差异（如地址写法）按优先级自动取值。
- 会影响请求或金额的差异（入职/离职日期、月工资、是否签合同、辞退方式）不自动选，弹卡问用户以哪个为准，两个值都留档（`st.archive`）。用户确认事实后，AI 不能直接改这些字段。
- 用户说过或传过的信息由代码带到后面所有地方：对话里的姓名、电话、公司地址直接填进申请书；说过的材料（有社保、微信辞退）自动勾上证据；营业执照住所带出注册地城市。

**第一轮对话不默认用户什么都不懂**：用户可以一次把经过、自己的结论（想主张什么、自己算的金额）和材料都发过来（对话框「＋材料」，每张由模型判断类型再读字段）。读到的直接进信息链，后面各页不再问；用户的结论由代码核对：能不能主张（不能的说明是哪条事实排除了），金额按法定公式重算后和用户的数对照。缺的才继续追问。

申请书只在法定必填项（当事人、请求、事实与理由）缺失时不让导出；证据不足不上锁，只在请求上标「需补证」，避免时效紧的用户被卡住。

法律判断（法条、计算口径、地区参数）一律以律师方向的校准文档为准，代码不自行决定。

## 目录

| 路径 | 内容 |
| --- | --- |
| `rules/rules.js` | 法条库、计算参数、请求目录、分档条件、证据和抗辩模板。律师改规则只改这里 |
| `rules/regions.js` | 地区表：全部省级默认值 + 市级覆盖；社平工资、最低工资按年度保存，各地口径字段 |
| `engine/facts.js` | 事实清单、追问顺序、「不确定」换问法、无模型时的关键词抽取 |
| `engine/engine.js` | 计算引擎与分析：2N / N / 代通知金、二倍工资差额、欠薪、要件判断、三档、主张值/保守值 |
| `engine/flow.js` | 流程状态机、参数确认、申请书必填项与请求句式、事实与理由校验 |
| `engine/docs.js` | 材料识别：每类材料读哪些字段、识别结果写到哪里 |
| `web/app.js`、`index.html` | 7 个页面（P0 描述 → P6 申请书） |
| `test/` | 引擎与流程测试，含校准文档里的算例 |

## 规则依据

计算规则以《劳动仲裁法条库与计算规则校准》为准：https://claude.ai/artifact/XJREhKY3TfHcyschHTcRnk 。地区工资数据目前全部为空，页面提示用户自行填写。
